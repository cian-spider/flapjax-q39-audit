Why the set is complete

The treasury is a single EOA, so its nonce is a gapless counter. Nonce 72 is at block 127067713 (2026-10-11T18:30:35Z, before the window). Nonce 307 is at block 128795971, the last treasury transaction inside the window. The nonce at the window's end block is 0x134 = 308, so nonce 308 is the first transaction after it. Nonces 73 through 307 are contiguous and every one of them falls inside the window: 235 transactions, no gaps, nothing dropped. That is a stronger statement than "a scan found these", because a missed transaction would show up as a missing nonce.

One honest caveat, because it changes the reading and should not be hidden: if the rule is meant as "$1 of escrow per question" and this single deposit funded two questions at about $0.95 each, then it is compliant. Chain data cannot show how many questions an escrow deposit covers, so I mark the rule BROKEN against the wording as published and say exactly why the alternative reading exists.

How to re-check it

  1. The set. eth_getTransactionCount(treasury, 0x79391CC) returns 0x49 (73) and at the end block

0x7AE0B60 returns 0x134 (308). Then eth_getTransactionBySenderAndNonce(treasury, n) for n = 73..307 returns the 235 transactions, each with its block number. Any missing nonce would be visible immediately. This method needs no explorer and no indexer, which is why it was used. 2. Value and gas. Each transaction's value is the BNB out; receipt.gasUsed * receipt.effectiveGasPrice is the gas. Both are in the CSV. 3. Buybacks. Read the token Transfer logs in each swap: FLAPJAX moves from the pool 0xcA93EC685b8623688E6B236f9068034B298c2150 to the treasury, never the reverse. 4. The bridge. Open the Across FundsDeposited log on 0x4e8e101924ede233c13e2d8622dc8aed2872d505: destination chain 8453, output token Base USDC, output amount 1.898595 USDC. 5. USD. https://api.binance.com/api/v3/klines?symbol=BNBUSDT&interval=1m&startTime=<minute> and take the close. The minute is printed in every row.

Endpoints used: 56.rpc.thirdweb.com for historical state and eth_getTransactionBySenderAndNonce, bsc-dataseed.binance.org and its siblings for receipts. Both are public and free.
